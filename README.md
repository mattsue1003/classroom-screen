# 教室螢幕 Classroom Screen

老師的互動教室螢幕：線上課程或實體教室白板都能用的單頁小工具集。

**網址：** https://mattsue1003.github.io/classroom-screen/

## 小工具
共 32 個，分六類：
- **時間**：時鐘、倒數計時、碼表、倒數日
- **隨機**：隨機抽籤、幸運轉盤、隨機分組、骰子、擲硬幣、隨機數字
- **課堂管理**：音量計、紅綠燈、工作模式、今日流程、呼吸練習
- **互動回饋**：搶答遊戲（嵌入搶答大作戰，Kahoot 風格）、即時投票、心情回饋（出場票）、計分板、獎勵星星、計數器
- **內容與展示**：文字、便利貼、小白板、嵌入網頁（YouTube／Google 簡報、表單／Canva／Padlet／Wordwall…）、圖片、攝影機（實物投影）、QR Code

## 功能
- 視窗可拖曳、縮放、放大全螢幕；全螢幕畫筆圈重點
- 五種風格主題：玻璃光感、夜間深色、黑板教室、童趣繽紛、簡約紙本（工具列調色盤切換，會記住）
- 聚光燈、一鍵情境版面（上課開場、小組活動、互動問答、安靜自習）
- 背景、格線、場景儲存與匯出匯入
- 班級名單：存一次，抽籤、轉盤、分組都能載入
- 關錯視窗可復原；倒數計時重新整理後會繼續；時間到全螢幕提醒
- 一鍵自動排列視窗；上課時螢幕不休眠
- 所有資料存在瀏覽器本機，不上傳
- **學生用手機作答**：即時投票、心情回饋可「📱 開放學生作答」，畫面出現 QR Code 與 6 位數 PIN；學生掃碼（或開 `…/classroom-screen/?join` 輸入 PIN）就能用大按鈕作答，票數即時顯示在老師螢幕。每支手機一票、可改答案；老師可截止／繼續、歸零、改題目與選項，學生畫面同步更新。

## 學生作答怎麼運作
- 不需要伺服器或帳號：老師的瀏覽器就是主機，透過 [PeerJS](https://peerjs.com/)（WebRTC）與學生手機直接連線；PeerJS 公用伺服器只負責牽線，房間代號為 `classscreen-tw-<PIN>`。
- 學生端網址：`?join=<PIN>`（只有 `?join` 則顯示輸入 PIN 畫面）。每台裝置在 localStorage 存一個隨機裝置代號，用來限制一機一票。
- 老師重新整理頁面會取回同一個 PIN，學生手機會自動重新連線；關閉「開放學生作答」時學生畫面顯示已結束。
- 沒開放作答時不會載入任何連線程式，離線也能照常使用其他功能。

快速鍵：`F` 全螢幕、`H` 隱藏工具列、`P` 畫筆、`A` 排列、`空白鍵` 開始/抽/轉、`Ctrl/⌘+Z` 復原關閉、`Esc` 關閉、`?` 說明

單一 `index.html`，無需建置，直接開啟即可使用。
