# 教室螢幕 Classroom Screen

老師的互動教室螢幕：線上課程或實體教室白板都能用的單頁小工具集。

**網址：** https://mattsue1003.github.io/classroom-screen/

## 小工具
時鐘、倒數計時、碼表、隨機抽籤、隨機分組、骰子、隨機數字、文字、音量計、紅綠燈、工作模式、嵌入網頁（YouTube／Google 簡報／Padlet／Wordwall…）、QR Code、小白板、即時投票、計分板、今日流程、圖片。

## 功能
- 視窗可拖曳、縮放、放大全螢幕；全螢幕畫筆圈重點
- 背景、格線、場景儲存與匯出匯入
- 所有資料存在瀏覽器本機，不上傳

快速鍵：`F` 全螢幕、`H` 隱藏工具列、`P` 畫筆、`Esc` 關閉、`?` 說明

單一 `index.html`，無需建置，直接開啟即可使用。
